# Dyadic Shells, Version 11.7.23: Exact Two-Adic Counts for Fermat-Type Quadratic Sieves and the Hyperbolic Sieve

**Version 11.7.23**  ·  dyadic-shell preprint series, release 10  ·  2026-11-08

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.24051028.svg)](https://doi.org/10.5281/zenodo.24051028)

Exact count of residues A mod 2^m with A² − N a square, for every odd N and every m; the uniform sharp bound 1/24
(proving the value left as a conjecture in v11.5.17); the identity |L_{N,2^e,k}| = C_e(kN)/2 for Hittmeir's
hyperbolic sieve modulo powers of two. Version 11.5.17 is not modified.
