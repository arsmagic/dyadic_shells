# Dyadic Shell Structures in Semiprime Arithmetic: A Structural Framework for Structured-Prime Diagnostics

**Version 4.0**  ·  dyadic-shell preprint series, release 4 of 9  ·  2026-05-23

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.20350133.svg)](https://doi.org/10.5281/zenodo.20350133)

Introduces the dyadic-shell framework: semiprimes represented through dyadic-anchored triples (r, s, alpha) with 2^(2r) - s^2 = alpha*n, with the first structural diagnostics for structured primes and an RSA-100 worked example.
