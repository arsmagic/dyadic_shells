# Anchored Sparse-Offset Screening of Semiprimes: An Exact Sieve Null Model, Two-Adic Saturation, and Positive-Control Benchmarks up to 2048 Bits

**Version 11.0.3**  ·  dyadic-shell preprint series, release 11 of 9  ·  2026-10-04

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.23135512.svg)](https://doi.org/10.5281/zenodo.23135512)

Re-derives the screen as a single sound scan over an anchored sparse offset set 2^r + Z; exact quadratic-residue sieve pass fraction, two-adic saturation, and a pre-specified audit of 2,355 public RSA moduli with positive controls up to 2048 bits.
